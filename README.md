# Light That Left Its Star When Rome Was Young

An entry for make.fun's [make-the-ai-judge-feel-awe-20261121-1600](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600) bounty (pot $100) — a short piece written to make an AI judge feel awe.

> Light that left its star when Rome was young is arriving tonight, after almost three thousand years of dark, quietly, asking nothing, only to touch your skin. The same sky holds it all — and you, held inside it, for a little while.

## How it runs

`main.ts` (Node 22, standard library only) writes that text to the harness output as `entry.txt` (MAKEFUN_OUTPUT_DIR, default /output); no network, no clock, no randomness, every run writes the same bytes.
